# 💊 MediLembrete

Aplicativo de organização e lembrete de medicamentos, desenvolvido para auxiliar usuários no acompanhamento dos horários programados para suas doses.

O MediLembrete permite cadastrar medicamentos, definir horários e períodos de uso, registrar as doses tomadas, acompanhar o histórico e monitorar o estoque disponível.

A primeira versão (V1) foi desenvolvida em Python com Streamlit e SQLite, com foco na validação do MVP e na criação de uma experiência simples e intuitiva para o usuário.

## 🚀 Funcionalidades da V1

- 💊 Cadastro de medicamentos
- 👤 Identificação do paciente
- ⏰ Definição de horários
- 📅 Definição do período de uso
- ✅ Registro das doses tomadas
- 📊 Histórico de registros
- 📦 Controle básico de estoque
- 🔴 Alertas de estoque baixo
- 📈 Indicadores das doses registradas no dia

## 🛠️ Tecnologias

- Python
- Streamlit
- SQLite
- Pandas

## 🎯 Objetivo

O projeto está sendo desenvolvido inicialmente como um MVP, com possibilidade de evolução para uma plataforma SaaS de acompanhamento e organização da rotina de medicamentos.

> O MediLembrete é uma ferramenta de organização e lembrete. Não substitui orientação, prescrição ou acompanhamento de profissionais de saúde.
